#
# The torch pin matters. PyPI's default torch wheel is the CUDA build: about 4.6 GB
# larger on disk, and it takes peak memory from about 633 MB to about 944 MB, which
# is the difference between fitting a 1 GB host and not fitting it. This pipeline
# runs on CPU, so take the CPU wheel from PyTorch's own index.
